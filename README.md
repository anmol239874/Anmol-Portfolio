# Premium Portfolio Website

A premium, modern personal portfolio built with React, Vite, Tailwind CSS, Framer Motion, GSAP, and React Icons. The experience includes animated sections, a polished theme, project showcase, experience timeline, certifications, achievements, contact form, and floating social links.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`

## Highlights

- Luxurious brown and gold theme
- Responsive, recruiter-friendly layout
- Smooth motion and subtle interactions
- Project filtering and animated cards
- Contact form ready for EmailJS integration
